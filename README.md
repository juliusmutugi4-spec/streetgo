# 🚀 StreetGO

StreetGO is a modern social platform built with **Next.js, React, TypeScript, Supabase, and Capacitor**.

## 🌍 Live Demo

https://streetgo.app

---

## ✨ Features

- 💬 Real-time Messaging
- 📰 Social Feed
- ❤️ Likes & Comments
- 📸 Image Uploads
- 🎥 Video Uploads
- 📍 Maps Integration
- 🚗 Driver Services
- 📈 Prediction Engine
- 🔔 Live Notifications
- 📱 Android App

---

## 🛠 Tech Stack

- React
- Next.js
- TypeScript
- JavaScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Capacitor
- Mapbox
- GitHub
- Vercel
